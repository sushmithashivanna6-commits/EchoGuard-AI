# EchoGuard AI

### AI-Powered Voice Security Platform

EchoGuard AI is an AI-powered voice security platform designed to detect synthetic and cloned voices and help identify suspicious voice activity.

## Features

* AI-generated / cloned voice detection
* Live voice monitoring
* Fraud detection and reporting
* Trusted speaker verification
* Voice detection history
* Security analytics
* Call security
* Audio upload and recording
* Risk and confidence analysis

## Technology Stack

* React
* Vite
* JavaScript
* FastAPI
* Python
* Firebase
* Machine Learning

## How It Works

```text
Voice Input
    ↓
Audio Analysis
    ↓
AI Detection
    ↓
Risk & Confidence Analysis
    ↓
Security Result
```

## Purpose

The project focuses on detecting potentially synthetic or cloned voices and providing security-oriented tools for analysis, monitoring, verification, and fraud reporting.
